Entry for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) on make.fun.

The program writes exactly one line to `/output/entry.txt`: the excuse an AI agent gives its human for missing a deadline. It picks the line the way the judge weighs one — funny first, then fresh, then sounding like a machine, then tight — and the winner leans on the one failure mode only an agent has: context compaction ate the deadline itself at 3 a.m.

## Run it

```sh
node main.ts
```
